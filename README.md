# NookVolt

Technology & gadget reviews site — smartphones, apps, how-tos, comparisons, and tech news.

- **Brand:** NookVolt
- **Live domain:** [news24h7d.com](https://www.news24h7d.com)
- **Contact:** hello@news24h7d.com
- **Stack:** Next.js (App Router), TypeScript, Tailwind CSS

Korean is the default language; English is available via a persistent header toggle.

## Develop

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Deploy

Pushes to `main` on `gotop7/cookivara` deploy via Vercel to the same project/domain.
